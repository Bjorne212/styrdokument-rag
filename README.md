# Dokumentationssajten

Den här grenen innehåller bara dokumentationen och landningssidan för Styrdokumentsboten, publicerad med GitHub Pages på <https://bjorne212.github.io/styrdokument-rag/>.

Koden ligger i grenen `main`. Grenarna har ingen gemensam historik, så dokumentationen kan uppdateras utan att koden rörs, och den följer inte med när någon forkar eller kopierar `main`.

Sajten byggs av GitHub Pages med Jekyll. Inställning: *Settings → Pages → Deploy from a branch → `gh-pages` / `(root)`*.
